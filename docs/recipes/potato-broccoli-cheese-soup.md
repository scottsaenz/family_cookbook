# Potato Broccoli Cheese Soup

## Ingredients

- onions

- potatoes
- broccoli

## Instructions

2. Add sliced mushrooms.
3. Add chicken.
4. Add potatoes and broccoli.
5. Add cheese soup.
6. Pour into [unclear] dish.
