# Family Cookbook

Welcome to our digitized recipe collection — a searchable archive of recipes extracted from
cookbooks, magazine clippings, and handwritten recipe cards.

## Browse Recipes

Head to the [Recipes](recipes/index.md) section to browse all recipes, or use the **search bar** above
to find something specific.

You can also browse by category on the [Tags](tags.md) page.

## How It Works

Each recipe was photographed and processed using AI-powered text extraction. The original source
type (cookbook, magazine, handwritten) is noted in each recipe's metadata.
